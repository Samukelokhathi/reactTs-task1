# 🥤 Olipop Landing Page Clone

A modern and responsive landing page inspired by the Olipop website. 
This project was built using to practice 
component-based development, responsive layouts, and clean UI design.

---


## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Samukelokhathi/reactTs-task1.git
```

### Navigate into the project

```bash
cd reactTs-task1
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
